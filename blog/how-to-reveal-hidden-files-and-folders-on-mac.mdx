A missing `.env` file may simply be hidden in Finder. Hidden does not mean encrypted, protected, or excluded from a backup; it describes how a file is presented.

## Reveal files in Finder

Open the relevant folder and press Command–Shift–period. Hidden items appear dimmed. Press the shortcut again to hide them. This is usually enough for a quick inspection; there is no need to restart Finder or change a persistent preference.

<Highlight color="lemon">Showing a file changes its visibility, not its contents or permissions.</Highlight>

## Go directly to a known location

Press Command–Shift–G in Finder and enter `~/Library`. The tilde identifies your home directory, so this is your user Library rather than the system-wide `/Library`. You can also hold Option while opening Finder's Go menu to reveal Library.

For a project, enter its full directory path. If you cannot see a file, confirm you are in the right checkout before recreating it. Two repositories with the same folder name can have different local configuration.

## Inspect from Terminal

From the project directory:

```bash
pwd
ls -la
```

`pwd` confirms the directory; `ls -la` includes names starting with a dot and displays permissions. It does not print file contents. Avoid pasting `.env` contents into support chats when a filename or error message is sufficient.

<Highlight color="flame">A dot-prefixed filename is not a security boundary. Keep secrets out of public repositories and redact diagnostic output before sharing it.</Highlight>

## Separate three different questions

| Question | Check |
| --- | --- |
| Is it hidden in Finder? | Toggle hidden-file visibility. |
| Is it present in this directory? | Confirm the path and list the directory. |
| Is Git tracking it? | Run `git status --short` and, if needed, `git check-ignore -v .env`. |

A hidden file can be tracked by Git, and an ignored file can be visible in Finder. Likewise, a cloud placeholder is not necessarily downloaded. These are separate states that require separate checks.

When inspecting Library, copy a configuration before editing it and use the application's own settings or reset procedure when available. Deleting an unfamiliar directory because it looks like a cache can remove useful state.

For navigating by path, see [Apple's Finder guidance](https://support.apple.com/guide/mac-help/go-directly-to-a-specific-folder-mchlp1236/mac).

<RainbowHighlight block>Confirm the location and visibility first; change a hidden file only when you understand its role.</RainbowHighlight>
