A heart that changes expression is a small stateful control. Build the state and input behavior first, then add motion as feedback. The example below uses an original simple SVG path and requires no icon package.

<Highlight color="lemon">Use a native button so keyboard activation and focus work without recreating them on an SVG element.</Highlight>

## Save one complete HTML file

Save this as `index.html` and open it in a browser. The label stays stable while `aria-pressed` communicates the toggle state.

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Heart toggle</title>
  <style>
    body { font-family: system-ui, sans-serif; padding: 2rem; }
    button { padding: 1rem; border: 2px solid #333; background: white; }
    button:focus-visible { outline: 3px solid #2463eb; outline-offset: 4px; }
    svg { display: block; width: 8rem; height: 8rem; }
    button[aria-pressed="true"] svg { animation: beat 450ms ease-out; }
    @keyframes beat { 50% { transform: scale(1.08); } }
    @media (prefers-reduced-motion: reduce) {
      button[aria-pressed="true"] svg { animation: none; }
    }
  </style>
</head>
<body>
  <button type="button" id="reaction" aria-pressed="false">
    <svg viewBox="0 0 100 100" aria-hidden="true">
      <path id="shape" fill="#b42348"
        d="M50 88 C20 67 6 48 10 28 C14 8 39 8 50 25 C61 8 86 8 90 28 C94 48 80 67 50 88Z" />
      <circle cx="35" cy="40" r="4" />
      <circle cx="65" cy="40" r="4" />
      <path id="mouth" d="M35 64 Q50 48 65 64" fill="none" stroke="#111" stroke-width="4" />
    </svg>
    Make the heart happy
  </button>
  <script>
    const button = document.querySelector('#reaction');
    const mouth = document.querySelector('#mouth');
    const shape = document.querySelector('#shape');
    button.addEventListener('click', () => {
      const happy = button.getAttribute('aria-pressed') !== 'true';
      button.setAttribute('aria-pressed', String(happy));
      mouth.setAttribute('d', happy ? 'M35 54 Q50 72 65 54' : 'M35 64 Q50 48 65 64');
      shape.setAttribute('fill', happy ? '#e94c70' : '#b42348');
    });
  </script>
</body>
</html>
```

## Understand the two states

The button is initially unpressed, with a sad mouth. A click toggles the boolean state, updates the SVG path, and changes the fill. Native button activation handles Enter and Space as well as pointer input. The SVG is hidden from assistive technology because the button's text provides its name.

The mouth path changes immediately; this example does not claim to smoothly morph SVG geometry. Only a short scale animation plays when switching to happy. Unlike an infinite heartbeat, it finishes quickly and does not compete continuously with the rest of the page.

<Underline>Keep one source of truth for the interaction.</Underline> Here the pressed attribute determines the next state. In React, keep that state in React and derive the attributes and path rather than also attaching a separate DOM listener.

## Check more than the mouse click

1. Press Tab and confirm the outline remains visible.
2. Toggle with Space and Enter; confirm each action changes the state once.
3. Inspect the accessible name and pressed state in developer tools.
4. Enable reduced motion and confirm the expression changes without scaling.
5. Try browser zoom and a narrow viewport.

The [reduced-motion media feature](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion) lets the animation follow the user's preference. Essential feedback remains in the face and pressed state even when motion is disabled.

If this becomes a persisted “like” control, add pending, failure, and retry behavior tied to the server result. This local toggle alone does not save a reaction or prevent duplicate requests.

<RainbowHighlight block>Make the control understandable and operable first, then let animation reinforce its state.</RainbowHighlight>
