まずは `box-sizing: border-box`、余白の一貫性、読みやすい行間、柔軟な画像を整えます。

```css
*, *::before, *::after { box-sizing: border-box; }
img { max-width: 100%; height: auto; }
```

色や角丸を場当たり的に増やすより、CSS変数でトークンを決める方が保守しやすくなります。モバイル幅で崩れないか、キーボード操作でも状態が分かるかを最後に確認しましょう。
