日時の扱いはOSとファイルシステムで異なります。大事なファイルは先にバックアップしてください。

### macOS
更新日時は `touch` で変更できます。

```shell
touch -t 202509151200 my-file.txt
```

作成日時の変更には追加ツールやメタデータ操作が必要になる場合があります。

### Windows
PowerShellでは `LastWriteTime` などを操作できます。

```powershell
(Get-Item .\my-file.txt).LastWriteTime = Get-Date "2025-09-15 12:00"
```

表示だけを整えたいのか、監査上の意味を持つ日時を変更したいのかを区別しましょう。
