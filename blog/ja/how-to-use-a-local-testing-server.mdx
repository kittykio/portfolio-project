ローカルサーバーを使うと、モジュール、fetch、ルーティングを本番に近い形で確認できます。

```shell
python3 -m http.server 8000
npx json-server --watch db.json --port 3001
```

前者は静的ページの確認、後者はAPIのプロトタイプに向いています。ポート番号と環境変数はREADMEに残し、テスト用データを実データと混ぜないようにしましょう。
