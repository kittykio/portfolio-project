プロフィールREADMEは自己紹介ではなく、次に見てほしい場所への案内です。

### 入れるとよいもの
- ひとことで分かる専門性や関心
- 注目プロジェクトへのリンク
- 使用技術は厳選して表示
- 連絡先やポートフォリオ

バッジや統計を増やしすぎるより、更新しやすい内容を短く置く方が伝わります。自分らしい一文と、実際に動く作品を中心にしましょう。
