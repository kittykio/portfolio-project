Ubuntuでは、入力メソッドとキーボード配列の両方を確認します。

```shell
sudo apt update
sudo apt install ibus-mozc
```

設定から **Keyboard** と **Input Sources** を開き、日本語（Mozc）を追加します。反映されない場合はログアウト・ログインし、IBusの設定でMozcが有効か確認してください。切り替えショートカットは、普段の開発環境と衝突しないものに変えると快適です。
