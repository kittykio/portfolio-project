隠しファイルや隠しフォルダは、macOSの大切な一部です。システム設定、アプリケーションデータ、設定ファイルなど、Macを正しく動かすための情報が保存されています。誤って変更しないよう初期状態では隠されていますが、開発、トラブルシューティング、詳細な設定を行うときには表示したいことがあります。

このガイドでは、Macで隠しファイルと隠しフォルダを表示する3つの簡単な方法を紹介します。

### 方法1: Finderのキーボードショートカットを使う

一時的に隠しファイルを表示するなら、Finderに組み込まれたショートカットが最も手軽です。

1. **Finder**を開きます。
2. 任意のフォルダに移動します。
3. **Command + Shift + .（ピリオド）** を押します。
4. 隠しファイルと隠しフォルダが半透明で表示されます。
5. もう一度同じショートカットを押すと、再び隠せます。

一時的に確認したいだけの場合に最適です。

### 方法2: Terminalで常に表示する

Terminalを使う場合は、Finderが常に隠しファイルを表示するよう設定できます。

**Terminal**アプリを開き、次を実行してください。

```shell
defaults write com.apple.finder AppleShowAllFiles true
killall Finder
```

Finderが再起動し、すべての隠しファイルが見えるようになります。

再び隠すには、次を実行します。

```shell
defaults write com.apple.finder AppleShowAllFiles false
killall Finder
```

隠しファイルを頻繁に扱う場合に便利な方法です。

### 方法3: 非表示のLibraryフォルダにアクセスする

ユーザーの**Library**フォルダは初期状態では非表示ですが、アプリケーションの設定やキャッシュによく使われています。

アクセスするには、次の手順を行います。

1. **Finder**を開きます。
2. メニューバーの**移動**をクリックします。
3. **Option（Alt）**キーを押したままにします。
4. メニューから**ライブラリ**を選びます。

Finderの表示設定を変えずにLibraryフォルダへアクセスできる、最も安全な方法です。

### 気をつけること

隠しファイルにはアクセスできますが、その多くはmacOSやインストール済みアプリケーションに欠かせません。目的を理解していないファイルは変更・削除しないでください。アプリケーションやOSが予期しない動作をする原因になります。

ほとんどの場合、必要なときだけ一時的に表示できるFinderのキーボードショートカットが、もっとも簡単で安全です。
