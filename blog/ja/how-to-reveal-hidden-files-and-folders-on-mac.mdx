見つからない`.env`は、Finderで非表示になっているだけかもしれません。隠しファイルという状態は表示方法を表し、暗号化や保護、バックアップ除外を意味しません。

## Finderで表示する

対象フォルダーを開いてCommand–Shift–ピリオドを押すと、隠し項目が薄く表示されます。もう一度押すと非表示に戻ります。一時的な確認なら、Finderの再起動や恒久的な設定変更は通常不要です。

<Highlight color="lemon">ファイルを表示しても、その内容やアクセス権は変わりません。</Highlight>

## 分かっている場所へ直接移動する

FinderでCommand–Shift–Gを押し、`~/Library`を入力します。`~`は自分のホームなので、システム共通の`/Library`とは異なります。「移動」メニューでOptionを押してLibraryを表示する方法もあります。

プロジェクトならフルパスを入力します。ファイルを作り直す前に、正しい作業コピーを開いているか確かめてください。同名のフォルダーでもローカル設定は異なります。

## ターミナルから確認する

プロジェクト内で次を実行します。

```bash
pwd
ls -la
```

`pwd`は現在地、`ls -la`はドットで始まる名前や権限を表示します。内容そのものは表示しません。相談時に必要なのがファイル名やエラーだけなら、`.env`の中身まで貼り付けないようにします。

<Highlight color="flame">ドットで始まる名前は安全性を保証しません。秘密情報は公開リポジトリへ入れず、共有する診断結果から除きます。</Highlight>

## 三つの状態を区別する

| 確認したいこと | 方法 |
| --- | --- |
| Finderで非表示か | 隠し項目の表示を切り替える |
| この場所に存在するか | パスと一覧を確認する |
| Gitで追跡されているか | `git status --short`や`git check-ignore -v .env`で確認する |

隠しファイルでもGit管理でき、Gitの無視対象でもFinderに表示できます。クラウドのプレースホルダーが未ダウンロードの場合もあります。それぞれ別の状態として確認します。

Libraryの設定を編集するなら先にコピーし、可能ならアプリの設定画面や公式の初期化方法を使います。キャッシュらしく見えるだけでフォルダーを削除すると、必要な状態まで失うことがあります。

パスによる移動は[AppleのFinderガイド](https://support.apple.com/guide/mac-help/go-directly-to-a-specific-folder-mchlp1236/mac)も参考になります。

<RainbowHighlight block>まず場所と表示状態を確かめ、役割が分かってから隠しファイルを変更しましょう。</RainbowHighlight>
