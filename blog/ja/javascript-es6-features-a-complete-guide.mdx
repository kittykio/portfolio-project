ES6は、より安全で表現しやすいJavaScriptを書くための基礎です。`let` と `const`、アロー関数、テンプレートリテラル、分割代入、スプレッド構文、Promise、class、modulesを少しずつ使いましょう。

```js
const greeting = ({ name }) => `Hi, ${name}!`;
```

新しい構文そのものより、意図が伝わり、副作用が追いやすいコードにすることが大切です。
