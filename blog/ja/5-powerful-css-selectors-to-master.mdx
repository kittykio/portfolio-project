CSSセレクタを使い分けると、余計なクラスを増やさずに意図を表現できます。

### `:is()` と `:where()`
複数の候補をまとめたいときに便利です。`:where()` は詳細度を増やさないため、ベーススタイルに向いています。

```css
:where(article, aside) a { color: var(--flame-500); }
```

### `:has()`
親要素を子要素の状態で選べます。対応ブラウザでは、フォームやカードの状態表現をシンプルにできます。

```css
.card:has(input:checked) { background: var(--lemon); }
```

### 属性・兄弟・構造セレクタ
`[data-state="open"]`、`+`、`~`、`:nth-child()` は、意味のあるマークアップを保ちながら細かな見た目を制御できます。便利だからと深くネストしすぎず、読みやすさと詳細度の低さを優先しましょう。
