ユーザーフォルダ名の変更は影響範囲が広いため、バックアップと復元ポイントを作成してから始めます。別の管理者アカウントでサインインし、プロファイルフォルダ、レジストリの `ProfileImagePath`、OneDriveの同期先を順に確認します。急いで直接名前を変えず、再起動後にアプリと同期状態を丁寧に検証してください。
