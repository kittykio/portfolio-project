表情が変わるハートは、状態を持つ小さなコントロールです。先に状態と操作を整え、動きは反応を補うために追加します。次の例は簡単な独自のSVGパスを使い、アイコンパッケージは不要です。

<Highlight color="lemon">SVGにボタンの動作を再実装せず、ネイティブのbuttonでキーボード操作とフォーカスを利用します。</Highlight>

## 一つのHTMLとして保存する

`index.html`として保存してブラウザーで開きます。ラベルは固定し、切り替え状態を`aria-pressed`で伝えます。

```html
<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Heart toggle</title>
  <style>
    body { font-family: system-ui, sans-serif; padding: 2rem; }
    button { padding: 1rem; border: 2px solid #333; background: white; }
    button:focus-visible { outline: 3px solid #2463eb; outline-offset: 4px; }
    svg { display: block; width: 8rem; height: 8rem; }
    button[aria-pressed="true"] svg { animation: beat 450ms ease-out; }
    @keyframes beat { 50% { transform: scale(1.08); } }
    @media (prefers-reduced-motion: reduce) {
      button[aria-pressed="true"] svg { animation: none; }
    }
  </style>
</head>
<body>
  <button type="button" id="reaction" aria-pressed="false">
    <svg viewBox="0 0 100 100" aria-hidden="true">
      <path id="shape" fill="#b42348"
        d="M50 88 C20 67 6 48 10 28 C14 8 39 8 50 25 C61 8 86 8 90 28 C94 48 80 67 50 88Z" />
      <circle cx="35" cy="40" r="4" />
      <circle cx="65" cy="40" r="4" />
      <path id="mouth" d="M35 64 Q50 48 65 64" fill="none" stroke="#111" stroke-width="4" />
    </svg>
    ハートを笑顔にする
  </button>
  <script>
    const button = document.querySelector('#reaction');
    const mouth = document.querySelector('#mouth');
    const shape = document.querySelector('#shape');
    button.addEventListener('click', () => {
      const happy = button.getAttribute('aria-pressed') !== 'true';
      button.setAttribute('aria-pressed', String(happy));
      mouth.setAttribute('d', happy ? 'M35 54 Q50 72 65 54' : 'M35 64 Q50 48 65 64');
      shape.setAttribute('fill', happy ? '#e94c70' : '#b42348');
    });
  </script>
</body>
</html>
```

## 二つの状態を理解する

初期状態は未押下で悲しい口です。操作すると真偽値、口のパス、塗りを変えます。ネイティブボタンなのでEnter、Space、ポインターで動きます。名前はボタン内の文字で伝え、SVGは読み上げ対象から外します。

口は即座に変わります。SVG形状を滑らかに変形する例ではありません。笑顔へ変えたときだけ短く拡大するため、無限の鼓動のようにページ上で動き続けません。

<Underline>操作の状態は一つの場所で管理します。</Underline> この例は押下属性を基準にします。Reactへ移すなら状態をReactで持ち、属性とパスをそこから導きます。別のDOMイベントと二重管理しません。

## マウス以外も確認する

1. Tabで移動し、輪郭が見えるか確認する。
2. SpaceとEnterで、一回ずつ状態が変わるか確認する。
3. 開発者ツールで名前と押下状態を調べる。
4. 動きを減らす設定で、拡大せず表情だけ変わるか試す。
5. 拡大表示や狭い画面でも試す。

[動きを減らすメディア特性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)で利用者の設定を尊重します。アニメーションがなくても、表情と押下状態で反応は残ります。

保存する「いいね」に発展させるなら、通信中、失敗、再試行をサーバーの結果と結び付けます。このローカル切り替えだけでは保存や重複送信の防止はできません。
