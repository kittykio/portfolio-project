小さなSVGでも、状態を分けると表情豊かなインタラクションになります。

```css
.heart { transform-origin: center; animation: beat 1s ease-in-out infinite; }
@keyframes beat { 50% { transform: scale(1.08); } }
```

クリック時にクラスを切り替え、目や口のパス、色、アニメーション速度を変えます。`prefers-reduced-motion` も用意し、動きが苦手な人には静かな状態を見せるのが大切です。
