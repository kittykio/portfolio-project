Macのリセットとは、個人データを消去し、クリーンなmacOSのセットアップ状態へ戻すことです。売却・譲渡の前、解決しないソフトウェア問題があるとき、開発環境をゼロから構築し直したいときに行います。

<Highlight color="flame">リセットすると、アカウント、アプリ、設定、ローカルファイルが完全に削除されます。必要なデータを必ずバックアップしてから始めてください。</Highlight>

正しい方法はMacの種類によって異なります。Appleシリコン搭載Macでは電源ボタンを長押しし、Intel Macでは**Command-R**で復旧モードを起動します。対応する新しいMacでは、通常、**すべてのコンテンツと設定を消去**が最も簡単です。

## 一般ユーザー向け

日常の仕事、学習、写真、書類、個人用アプリにMacを使っている場合は、この手順が安全で分かりやすい方法です。

### 1. Macの種類を確認する

**Appleメニュー → このMacについて**を開きます。

- M1、M2、M3、M4以降などのApple製チップが表示される場合は、**Appleシリコン搭載Mac**です。
- Intelプロセッサが表示される場合は、**Intel Mac**です。

復旧モードの起動方法は、この違いによって決まります。

### 2. ファイルをバックアップする

外付けドライブを接続し、**システム設定 → 一般 → Time Machine**を開きます。ドライブをバックアップディスクとして追加し、最初のバックアップが完了するまで待ちます。

重要なクラウドファイルの同期も完了していることを確認し、バックアップからいくつかのファイルを実際に開いてください。復元できることを確認して初めて、バックアップを信頼できます。

会社や学校が管理しているMacの場合は、自分でリセットせず管理者へ連絡してください。

### 3. 利用できる場合は「すべてのコンテンツと設定を消去」を使う

macOS Monterey 12以降を搭載したAppleシリコンMac、およびApple T2セキュリティチップ搭載Intel Macでは、この方法が推奨されます。

1. **Appleメニュー → システム設定**を開く。
2. **一般 → 転送またはリセット**を選ぶ。
3. **すべてのコンテンツと設定を消去**をクリックする。
4. 管理者パスワードを入力する。
5. 削除される項目を確認する。
6. Macが再起動するまで消去アシスタントの案内に従う。

消去アシスタントは、ユーザーアカウント、アプリ、設定、個人データを削除します。また、Appleのサービスからサインアウトし、「探す」とアクティベーションロックを解除します。

**こんにちは**の画面が表示されたら、次のように進めます。

- 自分で使い続ける場合は、設定アシスタントを完了する。
- 売却・譲渡する場合は、新しいアカウントを作らずにシステム終了する。

この項目がない場合やMacを通常起動できない場合は、macOS復旧を使います。

### 4. macOS復旧を起動する

#### Appleシリコン搭載Mac

1. Macを完全にシステム終了する。
2. **電源ボタンを押し続ける**。
3. **起動オプションを読み込み中**と表示されるまで押し続ける。
4. **オプション**を選び、**続ける**をクリックする。
5. 求められた場合は管理者を選び、パスワードを入力する。

#### Intel Mac

1. Macを再起動するか電源を入れる。
2. すぐに**Command-R**を押し続ける。
3. Appleロゴ、回転する地球儀、または起動画面が表示されたらキーを放す。
4. 求められた場合はパスワードを入力する。

Intel Macで**Option-Command-R**を使うと、互換性のある最新のmacOSがインターネット復旧から提示されます。**Shift-Option-Command-R**では、購入時のmacOSまたは現在入手できる最も近いバージョンが提示されます。

### 5. 起動ディスクを消去する

バックアップの完了を確認してから進めてください。

1. macOS復旧で**ディスクユーティリティ**を開く。
2. 内蔵ディスクが分かりにくい場合は、**表示 → すべてのデバイスを表示**を選ぶ。
3. 通常は**Macintosh HD**という名前のmacOSボリュームを選ぶ。
4. **消去**または**ボリュームグループを消去**をクリックする。
5. 名前を`Macintosh HD`、フォーマットを**APFS**にする。
6. 消去を確認し、完了後にディスクユーティリティを終了する。

<Highlight color="flame">選択したディスクを慎重に確認してください。バックアップが入った外付けドライブは絶対に消去しないでください。想定した内蔵ボリュームが見つからない場合は、確定する前に中止しましょう。</Highlight>

### 6. macOSを再インストールする

復旧画面で**macOSを再インストール**を選び、**続ける**をクリックして、インストール先に`Macintosh HD`を指定します。インストール中はMacを電源と安定したインターネットへ接続してください。

Macが数回再起動したり、一時的に画面が暗くなったりすることがあります。ディスクを消去せずにmacOSを再インストールしただけでは、通常、ユーザーデータは保持されます。事前の消去によって完全なリセットになります。

### 7. リセットを完了する

インストール後に設定アシスタントが開きます。

- 自分で使う場合は、設定、macOSの更新、ファイルの復元を行う。
- 売却・譲渡する場合は、設定アシスタントで**Command-Q**を押してシステム終了する。

以前の所有者のApple Accountを求められた場合は、その人がアカウントからMacを削除する必要があります。ディスク消去ではアクティベーションロックを回避できません。

## 開発者向け

開発者も上のリセット手順を使いますが、Time MachineやGitのリモートだけでは保存できない重要なデータが開発環境に残っていることがあります。消去前に次の項目を確認し、再インストール後は意図的に環境を再構築しましょう。

### 1. 外部に保存されていない作業を保護する

作業中の各リポジトリで、コミットされていないファイルと追跡対象外ファイルを確認します。

```shell
git status --short
```

リモートに置くべき変更はコミットしてプッシュします。ローカルのフィクスチャ、個人メモ、テスト証明書、大容量の開発素材など、コミットしないファイルは別途バックアップしてください。

次のデータも確認します。

- ローカルデータベースとデータベースコンテナ。
- 再作成できない仮想マシンやエミュレーターのデータ。
- 同期されていないデザイン素材とプロジェクト文書。
- パッケージレジストリ設定と非公開の証明書。
- アプリのライセンス情報と復旧コード。
- 同期していないローカルテスト用ブラウザプロファイル。

Dockerボリューム、`.gitignore`対象ファイル、リポジトリ外のファイルはGitに含まれません。

### 2. 開発環境を一覧化する

再インストールしたいツールを記録します。Homebrewでは再現可能な一覧を作成できます。

```shell
brew bundle dump --file=~/Brewfile
```

非公開tapや機密情報が含まれていないか確認してから、生成された`Brewfile`をバックアップします。

主要なランタイムも記録します。

```shell
node --version
python3 --version
git --version
```

グローバルな一覧よりも、`.nvmrc`、`.node-version`、`.python-version`、`.tool-versions`などのプロジェクトファイルを優先してください。dotfilesリポジトリを使っている場合は、最新の状態になっていることを確認します。

### 3. 認証情報を安全に扱う

リセット後に必要な認証情報を確認しますが、シークレットの値を公開リポジトリへ保存してはいけません。

- 消去するMacだけに頼らず、パスワードマネージャーへサインインできることを確認する。
- SSHキーを引き継ぐ必要がある場合だけ安全にバックアップし、それ以外はリセット後に新しく作る。
- 過去の署名IDが必要な場合はGPGキーを安全に書き出す。
- 2要素認証の復旧コードをMac以外に保管する。
- Git、クラウド、パッケージレジストリ、デプロイサービスで再認証が必要なアカウントを記録する。

セキュリティ上の懸念からリセットする場合は、古い認証情報を失効させ、リセット後に新しく作るほうが安全です。

### 4. Macをリセットする

一般ユーザー向けセクションから、Macに合う手順を実行します。

- 利用できる場合は**すべてのコンテンツと設定を消去**を優先する。
- Appleシリコンでは電源ボタンを長押しして復旧を起動する。
- Intelでは起動時に**Command-R**を押し続ける。
- ディスクユーティリティでは正しい内蔵macOSボリュームだけを消去する。
- macOSを再インストールして設定アシスタントを完了する。

マルウェアや環境の侵害が疑われる場合は、システム全体をバックアップから戻さないでください。個人ファイルを選んで復元し、ツールは信頼できる配布元から再インストールします。

### 5. クリーンな開発環境を再構築する

セットアップ後、最初にmacOSのアップデートをすべて適用します。次にAppleのCommand Line Toolsをインストールします。

```shell
xcode-select --install
```

[Homebrew公式サイト](https://brew.sh/ja/)の最新コマンドでHomebrewをインストールし、確認済みのパッケージを復元します。

```shell
brew bundle --file=~/Brewfile
```

dotfilesを慎重に復元し、各プロジェクトで使うバージョンマネージャーを導入します。古いシェル設定を確認せずに丸ごとコピーしたり、macOS標準ツールを置き換えたりしないでください。

### 6. アクセスを復元してプロジェクトを確認する

SSHキーやGPGキーを新規作成または復元し、Gitホスティング、パッケージレジストリ、クラウド、デプロイサービスへ認証します。各アプリには必要なmacOS権限だけを付与してください。

代表的なプロジェクトを1つ使って環境を確認します。

```shell
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT
git status
```

依存関係をインストールし、テストを実行し、ローカル開発サーバーを起動します。必要なデータベースや外部サービスへ接続できることも確認してください。

完了前のチェックリストです。

- [ ] 重要なリポジトリをプッシュまたはバックアップした。
- [ ] ローカルデータベースとGit対象外ファイルを保存した。
- [ ] パスワードマネージャーと2要素認証を利用できる。
- [ ] Command Line Tools、Git、ランタイム、パッケージマネージャーが動作する。
- [ ] 必要なSSHまたはGPG認証が動作する。
- [ ] 少なくとも1つのプロジェクトをインストール、ビルド、テスト、ローカル実行できる。
- [ ] 新しいTime Machineバックアップが完了した。

一般ユーザーにも開発者にも大切な原則は同じです。**先にバックアップし、Macの種類に合った方法でリセットし、復元後の環境を確認するまで古いバックアップを削除しないでください。**
