ES2015, often called ES6, introduced useful syntax and APIs. Learning the semantics matters more than replacing every old expression with a shorter one. This is a focused introduction, not a complete language reference.

## Const protects the binding

```js
const settings = { theme: 'light' };
settings.theme = 'dark'; // Allowed: the object is mutable.
let visits = 0;
visits += 1;
```

A `const` variable cannot be reassigned, but its object can still change. `let` and `const` have block scope; accessing them before initialization is an error. Use `let` when reassignment is part of the intended behavior.

<Highlight color="lemon">An immutable binding is not an immutable object.</Highlight>

## Arrow functions inherit this

```js
const doubled = [1, 2, 3].map(value => value * 2);
const counter = {
  value: 0,
  increment() { this.value += 1; }
};
counter.increment();
```

Arrows suit the callback above. Replacing `increment` with an arrow would stop it from receiving the object as its call-time `this`. Choose a function form for its behavior, not just its length. The [MDN arrow-function reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/Arrow_functions) explains these differences.

## Defaults and destructuring have precise boundaries

```js
function greet(name = 'Guest') { return `Hello, ${name}`; }
console.log(greet(undefined)); // Hello, Guest
console.log(greet(null));      // Hello, null
const { title = 'Untitled' } = { title: '' };
console.log(title);            // Empty string remains empty.
```

Defaults apply to `undefined`, not every falsy value. Decide whether an empty string or `null` is meaningful before normalizing it.

## Spread copies an array shallowly

```js
const original = [{ title: 'First' }];
const copy = [...original];
copy[0].title = 'Changed';
console.log(original[0].title); // Changed
const sum = (...values) => values.reduce((total, value) => total + value, 0);
```

Array spread expands an iterable; rest collects arguments. Neither creates independent nested objects. Object spread and `async`/`await` arrived after ES2015, so do not treat “modern JavaScript” and “ES6” as identical scopes.

## Modules and promises organize work

Use `export` and `import` in an ES module environment: a browser script with `type="module"`, or Node `.mjs` files. Module loading rules and paths depend on that environment.

```js
Promise.resolve(3)
  .then(value => value * 2)
  .then(value => console.log(value))
  .catch(error => console.error(error));
```

A promise represents eventual completion; return nested asynchronous work from a handler so the chain can follow it. Merely starting a promise does not make the caller wait. Classes, `Map`, `Set`, and iterators are other ES2015 topics to study separately once these foundations are clear.
