You can type Japanese on a US keyboard. A keyboard layout maps physical keys to symbols; an input method converts typed text into Japanese. Changing one does not automatically configure the other.

<Highlight color="lemon">Choose the layout that matches your physical keyboard, then add Mozc for Japanese conversion.</Highlight>

## Set the physical layout first

On Ubuntu Desktop with GNOME, open Settings and locate Keyboard → Input Sources. On some releases this appears under Region & Language. Add English (US) for a US keyboard or the appropriate Japanese layout for a JIS keyboard. Use the layout preview and test punctuation such as `@`, `:`, and parentheses.

Ubuntu documents input sources and switching in its [keyboard layout guide](https://help.ubuntu.com/stable/ubuntu-help/keyboard-layouts.html). Desktop environments other than GNOME may use different settings panels and input frameworks.

## Install and select the input method

If Japanese (Mozc) is not available, install the IBus integration through Ubuntu's package manager:

```bash
sudo apt update
sudo apt install ibus-mozc
```

Sign out and sign back in, then add Japanese (Mozc) as an input source. Use the input indicator to select it. Choose Hiragana mode if typing still produces direct Latin characters. Test `nihongo`, use Space to choose a conversion, and Enter to commit it.

A US physical keyboard can stay on a US mapping while Mozc provides conversion. If punctuation moves to unexpected keys only when Mozc is active, inspect the input method's layout settings rather than changing the whole system to JIS.

## Diagnose the symptom

| Symptom | First check |
| --- | --- |
| Wrong punctuation in every app | Physical layout selection |
| Latin characters with Mozc selected | Direct-input versus Hiragana mode |
| Mozc missing from the source list | Package installation and a fresh login |
| Failure in only one application | That application's input-method support |

<Highlight color="flame">Do not start by editing package-owned files under /usr/share. Updates can replace them, and a layout change there may affect more than the problem you are investigating.</Highlight>

If you use KDE or Fcitx, follow that environment's input-method setup instead of mixing frameworks blindly. Keep one known-working input source available so you can enter passwords and troubleshoot. Once conversion works, verify the switching shortcut in Settings; custom shortcuts and desktop versions can change it.
